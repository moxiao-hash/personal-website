# moxiao6657 个人主页：设计说明

**状态：** 已确认，待实施计划与开发。

## 目标

为 `moxiao6657` 制作一页式个人主页，清晰传达其「学生 · 正在学习 Vibe Coding 的人」的身份。网站应具备轻量、明亮的天蓝色审美和柔和的鼠标互动，并作为未来独立作品的总入口。

## 受众与成功标准

访客在数秒内应能知道网站主人是谁、正在学习什么、如何访问其 GitHub 或发送邮件；日后可以从主页进入已部署的作品。

首版成功标准：

- 电脑、平板和手机均可顺畅阅读和操作。
- 显示网名、身份介绍、学习主题、GitHub 和邮箱。
- 提供两个可扩展的作品入口，当前未上线时明确显示「即将上线」。
- 鼠标光晕和悬停动效不损害可读性或移动端性能。
- 构建产物可由任何普通静态 Web 服务器直接托管。

## 信息架构

页面是一个纵向滚动的单页，按以下顺序组织：

1. **Hero / 首屏**：`moxiao6657`、身份副标题与一句简短引导。
2. **About / 现在的我**：学生身份与探索 Vibe Coding、把想法实现为网页和小作品的简介。
3. **Learning Now / 正在学习**：Vibe Coding、网页开发、AI 工具三张轻量信息卡片。
4. **Projects / 我的作品**：可配置的作品卡片列表。首版显示两个「即将上线」占位卡片；每张正式卡片包含名称、简介、标签、作品链接和访问按钮。
5. **Connect / 找到我**：GitHub 链接与电子邮箱。
6. **Footer / 页脚**：简短签名，例如 `Built with curiosity by moxiao6657`。

## 视觉与交互

- **主色调**：明亮、轻盈的天蓝色渐变背景；文字使用白色与深蓝，保证对比度。
- **鼠标光晕**：桌面端出现低亮度、柔和、延迟跟随的天蓝光团，只作为背景层，不遮挡文字或交互元素。
- **进入与滚动**：首屏内容淡入；各内容区块进入视口时轻微上浮、淡入。
- **卡片交互**：学习卡片和作品卡片悬停时轻微抬升，边缘呈现天蓝光效；触摸设备无须悬停也可完整使用。
- **动效降级**：尊重系统的“减少动态效果”偏好，关闭或大幅减弱动画；移动端以静态柔光代替鼠标跟随。
- **排版**：大号英文网名搭配简练中文描述，留白充足，避免重型 3D、自动播放视频或游戏化界面。

## 技术架构与数据流

首版采用前端静态站点，不使用数据库、登录或后端 API。个人资料和项目卡片统一由一个可读的本地配置数据源驱动：页面渲染配置中的项目列表；新增项目时只需新增一条数据而无需复制或重做版式。

GitHub 和已上线作品使用标准锚点在新标签页打开，并添加安全的 `rel="noopener noreferrer"` 属性；邮箱使用正常的 `mailto:` 链接处理。没有 URL 的项目被渲染为不可点击的“即将上线”状态，避免死链。

## 部署与演进

首版可先部署到免费静态托管服务，也会输出不依赖特定平台的静态构建文件。后续迁移至自有服务器时，可将构建文件直接部署在 Nginx 或 Caddy 等普通 Web 服务器上。

主站将使用购买后的主域名。独立作品可部署到同一服务器或不同服务器，并通过子域名提供，例如 `project.example.com`；个人主页的 Projects 区块只需更新该作品的 URL。

将来如增加留言、订阅、登录、AI 功能或数据库，再分别添加后端服务；这些不属于第一版范围。

## 错误处理与可访问性

- 未配置 URL 的作品显示明确的未开放状态。
- 外链使用清晰的文字标签，邮箱链接提供可感知的用途。
- 文本与背景保持足够对比，键盘可访问链接与按钮均有清晰焦点样式。
- 动画尊重用户的减少动态效果偏好，确保页面在低性能设备上仍可用。
